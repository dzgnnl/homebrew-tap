# dzgnnl/tap

Homebrew tap for [TomTomSync](https://github.com/dzgnnl/TomTomSync), a macOS
menu bar app for TomTom sports watches.

```sh
brew install --cask dzgnnl/tap/tomtomsync
brew upgrade                      # update
brew uninstall --cask tomtomsync  # remove
```

The cask is updated automatically by TomTomSync's release workflow.
